# How to play

The Roguelike Binding of Briatte runs from the command line

## Getting starting

Clone the project

```shell
git clone https://github.com/ulyhmyges/BOB.git
cd binding_of_briatte
```

## Run the game

Build and execute the project in one step

```shell
make all 
```

## Build the project

Compile the project

```shell
make build
```

## Run the project

Run the project after building

```shell
make run
```

## Notes

Make sure you have make installed on your system

Run all commands from the project root directory (binding_of_briatte)
